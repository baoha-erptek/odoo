VAI TRÒ 5 · ĐỌC ~6 PHÚT

Thiết kế sản phẩm (PD) — Lặp file, duyệt, lưu kho

Em Tuấn, nhân viên thiết kế 26 tuổi, là PD chính của Hatafa. Mỗi ngày nhận 3–7 yêu cầu từ BA Lead: tạo mockup sản phẩm mới hoặc tùy chỉnh file cho đơn hàng cụ thể cá nhân hoá. Em lặp file qua Illustrator/Photoshop ngoài hệ thống, upload từng phiên bản vào Design Files kanban, chờ BA duyệt feedback, sửa lại. Khi BA cuối cùng chấp thuận, em archive các phiên bản cũ và lưu phiên bản cuối vào kho Design Files để sử dụng lại.

Hoạt động Luồng 1 + Luồng 3A Tham gia: 5–6 giờ/ngày

ABối cảnh — PD chạm vào hệ thống ở 2 luồng

Luồng 1: Tạo sản phẩm mới (Flow 1). BA Lead mở form Sản phẩm chuẩn, yêu cầu PD chuẩn bị file mockup cho sản phẩm đó. PD tạo trên Illustrator/Photoshop, upload qua Design Files trên form sản phẩm hoặc dán link Google Drive. File được lưu trong tab Files của form sản phẩm với versioning (v1, v2, v3…).

Luồng 3A: File thiết kế cho đơn cụ thể có cá nhân hoá (Flow 3A). Khi khách đặt đơn cá nhân hoá (ví dụ: khắc tên lên mug), BA gắn tag yêu cầu "Personalize file" vào đơn → hệ thống thông báo cho PD → PD tạo file từ template sản phẩm gốc + buyer text → upload vào đơn → BA duyệt → sẵn sàng in.

File chính được upload qua Google Drive link (nếu lớn hơn 2 MB) hoặc binary upload nhỏ ≤ 2 MB trực tiếp trên hệ thống. Kanban Design Files có 3 trạng thái: Pending (chờ duyệt), Approved (ba duyệt rồi), Rejected (BA yêu cầu sửa). BA Lead là approver duy nhất; PD tự duyệt sơ bộ, sau đó chỉnh sang Approved để BA review cuối.

ECâu hỏi mở và giới hạn hôm nay

Google Drive là kho chính cho file lớn: File > 2 MB nên upload lên Google Drive (kênh dùng chung của shop), dán link vào Design Files trên hệ thống. Hệ thống lưu link + preview, không copy file (tiết kiệm dung lượng, tránh trùng bản). Tuy nhiên, trách nhiệm lưu trữ dài hạn ở GDrive, không phải Odoo.

Binary upload ≤ 2 MB là giới hạn hệ thống: Odoo filestore có cấu hình `multichannel_hub.large_file_threshold_bytes` mặc định 2 MB — file lớn hơn sẽ timeout. Cần sử dụng GDrive link để vượt qua giới hạn này.

Tìm kiếm file cũ chưa dễ dàng: Hôm nay search Design Files chỉ theo tên file hoặc SKU sản phẩm, chưa có tag thêm. Nếu muốn tìm "tất cả file apron xanh", phải scroll Archive lâu hoặc nhớ tên sản phẩm. Có thể thêm tag vào file trong tương lai (ví dụ: #apron, #xanh, #ceramic).
