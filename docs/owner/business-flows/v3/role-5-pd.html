Thiết kế sản phẩm (PD)

Bạn lặp file thiết kế với nhóm, upload lên hệ thống, và chờ BA Lead hoặc RD duyệt. Hệ thống theo dõi trạng thái thiết kế (Draft → In Review → Ready) để QA có thể lọc và in đúng file.
Một ngày Đọc ~5 phút

Giờ giấc một ngày

  • 8:00 AM
    Mở Duyệt thiết kế
    Menu: Vận hành ▸ Công việc hằng ngày ▸ Duyệt thiết kế. Xem danh sách file thiết kế đang chờ duyệt (trạng thái "In Review").
  • 9:00 AM
    Lặp file thiết kế (nếu bị reject)
    Nếu file bị reject từ lần trước, bạn nhận được ghi chú lý do từ BA Lead. Sửa file theo ghi chú (ví dụ "ảnh nhòe", "font không khớp") và upload lại.
  • 10:00 AM
    Upload file thiết kế mới
    Mở form Design File hoặc SO → Tab "Design" → Upload file (PDF, PNG, v.v.) → Lưu. Hệ thống gán trạng thái "Draft" → "In Review" (chờ duyệt).
  • 11:00 AM
    Chờ duyệt từ BA Lead
    BA Lead sẽ review file thiết kế và approve (trạng thái → "Ready") hoặc reject (ghi chú lý do).
  • 2:00 PM
    Nếu approve → Lưu kho (Archive)
    Khi file được approve và SO đã in xong, lưu file vào kho ("Design Ready" hoặc "Archive" folder) để tham chiếu sau này nếu khách yêu cầu in lại.
  • 4:00 PM
    Nếu reject → Sửa lại
    Nhận ghi chú từ BA Lead, sửa file, upload lại. Vòng lặp cho đến khi approve.

Menu chính của bạn

  • Vận hành ▸ Công việc hằng ngày:
    • Duyệt thiết kế (view danh sách design files chờ duyệt)
  • Vận hành ▸ Giao hàng:
    • Design File Form (upload & quản lý file thiết kế)

Tóm tắt quyền hạn

Bạn được phép:

  • ✓ Xem danh sách design files chờ duyệt
  • ✓ Upload file thiết kế (PDF, PNG, v.v.)
  • ✓ Xem ghi chú từ BA Lead (lý do reject)
  • ✓ Lưu file thiết kế vào kho sau khi approve
  • ✓ Xem chi tiết SO liên quan đến design file
  • ✗ Phê duyệt design (chỉ BA Lead phê duyệt)
  • ✗ Yêu cầu push đơn sang Gearment (BA Lead làm)

Quy trình lặp thiết kế

  1. PD nhận yêu cầu: BA Lead hoặc khách yêu cầu thiết kế (ví dụ: "In bằng vải dù", "Màu xanh lá", "Logo ở góc phải").
  2. PD tạo file: Dùng Photoshop / Illustrator / Corel để vẽ thiết kế theo yêu cầu. File chứa đầy đủ layer, font, ảnh độ phân giải cao.
  3. PD upload: Export ra PDF hoặc PNG (≥300 DPI). Upload vào form Design File trong Odoo.
  4. BA Lead review: Xem trên màn hình và so sánh với yêu cầu. Nếu OK → Approve (trạng thái "Ready"). Nếu có vấn đề → Ghi chú lý do reject.
  5. Nếu reject: PD nhận ghi chú, sửa file, upload lại. Lặp cho đến approve.
  6. Khi approve: Hệ thống gán trạng thái "Design Ready". Sản xuất sẽ dùng file này để in.

Gợi ý nhanh

  • File thiết kế phải rõ ràng & đầy đủ. Nếu bị reject vì "ảnh nhòe" hoặc "font sai", lần sau sẽ cần sửa lại — tránh lãng phí thời gian.
  • Lưu lại file thiết kế sau khi approve. Nếu khách yêu cầu "in lại bản cũ", bạn có file sẵn thay vì tạo lại từ đầu.
  • Ghi chú BA Lead là feedback cho bạn. Đọc kỹ để biết lần tới cần cải thiện gì (ví dụ "font quá nhỏ", "màu sai tone").
  • Nếu có nhiều yêu cầu thiết kế, ưu tiên theo thứ tự từ Bảng điều hành (SLA 3 ngày).
