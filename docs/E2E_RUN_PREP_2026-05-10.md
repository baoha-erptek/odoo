## Failure-mode quick triage

| Symptom | Likely cause | Fix |
|---|---|---|
| §1 `MISSING: [...]` for some receipts | Gmail label missing on one of the messages, or the cron returned 0 results | Re-apply label; re-run §1 only via `--section 1` |
| §1 falls through to FALLBACK | All 4 OAuth ICPs unset | Apply step 1 above |
| §3 shows `image_1920` empty for several lines | Image cron didn't finish in 30s | Re-run §3 only after waiting; or run `_cron_download_etsy_images` from a shell |
| §5 `0/4 promoted` | GDrive folder ICP unset OR SA not Editor on folder | Apply steps 3 + 5 |
| §6 `outbound_ref=∅ http_status=0` | Gearment env vars missing | Apply step 6 |
| §8 `matched_targets=0/4` | xls was built but channel_order_ref didn't get populated on ingest | Verify `sale.order.channel_order_ref` is set after §1 — should equal `etsy_order_id` |
| §8b `no new log rows` | Drive folder empty (xlsx not uploaded) OR poller cron disabled | Re-run `build_gke_xls_for_e2e.py --upload-to-drive`; verify cron in Settings → Technical → Schedules |
