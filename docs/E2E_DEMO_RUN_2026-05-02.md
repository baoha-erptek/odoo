## Reproducing the run

```bash
# Build venv (one-time)
python3 -m venv --without-pip .venv-e2e
curl -sS https://bootstrap.pypa.io/pip/3.8/get-pip.py | .venv-e2e/bin/python
.venv-e2e/bin/pip install 'playwright<1.50' requests python-dotenv
.venv-e2e/bin/playwright install chromium

# Run all sections
.venv-e2e/bin/python scripts/e2e_demo_2026_05_02.py --section all

# Or one section
.venv-e2e/bin/python scripts/e2e_demo_2026_05_02.py --section 10
```

Screenshots overwrite on rerun. `.env` must contain `GEARMENT_API_SECRET` + `GEARMENT_API_KEY`.
